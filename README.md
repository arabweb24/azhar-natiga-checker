# azhar-natiga-checker · متابعة نتيجة الأزهر بالرقم القومي

<div dir="rtl">

أداة **مفتوحة المصدر** بتتابع موقع نتائج الأزهر
[natiga.azhar.eg](https://natiga.azhar.eg/) بالنيابة عنك، وتحاول تلقائيًا كل فترة
معقولة لحد ما النتيجة تظهر بالرقم القومي — وساعتها **تحفظ لقطة شاشة + نص النتيجة
وتنبّهك بصوت**. مفيدة في يوم ظهور النتيجة لما الموقع يكون مزحوم وبيفصل.

الأداة بتشتغل بمتصفح حقيقي (Playwright)، فبتتعامل مع الموقع زي أي مستخدم عادي.

</div>

---

## ⚠️ استخدام مسؤول / Responsible use

<div dir="rtl">

- الأداة للبحث عن **رقم قومي واحد (بتاعك أو بتاع أهلك)** — مش أداة لسحب نتائج الناس بالجملة.
- بتحترم الموقع: فاصل زمني افتراضي **~20 ثانية** بين المحاولات (الموقع نفسه بيفرض cooldown 5 ثواني)، وبتوقف الصور/الخطوط عشان تخفّف الحِمل.
- **من فضلك متقللش الفاصل الزمني عن اللازم** ومتشغّلش نسخ كتير في نفس الوقت — ده بيضغط على الموقع اللي أصلًا مزحوم.
- الأداة **مابتحلّش كابتشا** ولا بتحايل على أي حماية.

</div>

> The tool checks **one** national ID at a time. Please don't lower the interval
> or run many copies in parallel — the portal is already under heavy load on
> results day. No CAPTCHA solving, no anti-bot evasion.

## ▶️ التشغيل / Usage

### ⭐ الطريقة الأسهل — دبل كليك (بدون أوامر)

<div dir="rtl">

اعمل **دبل كليك** على ملف **`run.bat`** الموجود في الفولدر. هيفتح نافذة سوداء،
يطلب منك الرقم القومي — اكتبه واضغط Enter، والأداة تشتغل لوحدها.

- أول مرة بس هياخد دقيقة عشان يثبّت المكتبات تلقائيًا (لازم Node.js يكون متثبّت).
- سيبها شغّالة، وأول ما النتيجة تظهر هتسمع تنبيه وتتحفظ في فولدر `results/`.
- للإيقاف: اقفل النافذة أو اضغط `Ctrl + C`.

</div>

### الطريقة الأسرع — سطر الأوامر مباشرة

```bash
node src/index.js --id 30805152302986
```

<div dir="rtl">

هتفضل الأداة تحاول لحد ما النتيجة تظهر. أول ما تظهر:
- هتسمع صوت تنبيه 🔔
- هتتحفظ **لقطة شاشة** + **ملف نص** في فولدر `results/`
- هيتطبع ملخص النتيجة في الشاشة

للإيقاف في أي وقت اضغط `Ctrl + C`.

</div>

### الطريقة التانية — عن طريق ملف إعدادات

<div dir="rtl">

انسخ ملف المثال وسمّه `config.json` وحُط رقمك القومي جواه:

</div>

```bash
copy config.example.json config.json   # على ويندوز
# cp config.example.json config.json    # على لينكس/ماك
```

<div dir="rtl">

بعد كده شغّل:

</div>

```bash
node src/index.js
```

<div dir="rtl">

> ملف `config.json` **مستثنى من Git** (في `.gitignore`) عشان رقمك القومي يفضل خاص وميترفعش على GitHub.

</div>

## ⚙️ الخيارات / Options

| الخيار | الوصف | الافتراضي |
|---|---|---|
| `--id <رقم>` | الرقم القومي المراد البحث عنه | — |
| `--interval <ثواني>` | الفاصل بين المحاولات (أدنى 5) | `20` |
| `--max <عدد>` | أقصى عدد محاولات قبل التوقف | `500` |
| `--url <رابط>` | رابط الموقع | `https://natiga.azhar.eg/` |
| `--headed` | إظهار نافذة المتصفح (للمراقبة) | مخفي |
| `--config <ملف>` | مسار ملف إعدادات مخصص | `config.json` |
| `--calibrate` | بحث واحد + طباعة نص الصفحة (لضبط الكشف) | — |
| `--help` | عرض المساعدة | — |

مثال:

```bash
node src/index.js --id 30805152302986 --interval 25 --headed
```

## 🔧 الضبط عند الحاجة (Calibration)

<div dir="rtl">

الأداة بتكتشف ظهور النتيجة عن طريق **كلمات مفتاحية** موجودة في
[`src/config.default.json`](src/config.default.json) (زي «هذه النتيجة إرشادية»،
«المجموع»، «ناجح»...). لو الموقع غيّر صياغته أو الكشف مش مظبوط عندك، شغّل:

</div>

```bash
node src/index.js --calibrate --headed
```

<div dir="rtl">

ده بيعمل بحث واحد ويطبع **نص الصفحة كامل** + يحفظ لقطة شاشة، فتقدر تشوف الصياغة
الفعلية وتعدّل قوائم الكلمات في ملف الإعدادات:

- `successKeywords` — كلمات تدل إن **النتيجة ظهرت**.
- `notFoundKeywords` — كلمات تدل إن **الرقم غلط / مفيش نتيجة**.
- `errorKeywords` — كلمات تدل إن **الموقع مشغول** (يكمّل محاولة).
- `inputLabelHint` — تلميح لتحديد خانة الرقم القومي (افتراضي «قومي»).

</div>

## ❓ أسئلة شائعة

<div dir="rtl">

**بتشتغل على غير مصر؟** غالبًا لأ — الموقع محجوب خارج مصر. شغّلها من مصر.

شغّل `--calibrate` وعدّل `successKeywords`.
